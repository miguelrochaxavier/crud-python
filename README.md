## 💻 Projeto

<p align="left"> 
    <h3>Este repositório contém um projeto em Python que implementa um sistema simples de CRUD (Create, Read, Update, Delete) para gerenciamento de cargas. A aplicação permite adicionar, visualizar, atualizar e remover cargas de forma interativa via terminal, sendo ideal para fins educativos ou como base para projetos mais complexos.
    Clone o repositório e execute o script Python para testar as funcionalidades. O menu interativo guiará o usuário por todas as operações disponíveis. Instruções detalhadas podem ser encontradas no arquivo README.md.
    Este é um projeto open-source e está disponível sob a licença MIT. Contribuições são bem-vindas!
    Explore, experimente e contribua para tornar este sistema ainda mais completo e eficiente!
